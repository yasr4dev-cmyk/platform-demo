# Linkiraq MVP

منصة Link-in-bio عراقية مبنية بـ PHP + HTML5 + CSS + Bootstrap + MySQL، مع دعم العربية والكردية والإنكليزية.

## المزايا الحالية
- واجهة رئيسية عصرية ومتجاوبة مع الهاتف.
- تسجيل ودخول بالبريد الإلكتروني أو رقم الهاتف أو اسم المستخدم.
- صفحات شخصية عامة للمستخدمين.
- إضافة/حذف/إخفاء الروابط.
- احتساب المشاهدات والنقرات داخل MySQL.
- خطط Free / Plus / Pro بالدينار العراقي.
- جداول الاشتراكات والدفعات.
- لوحة مستخدم.
- لوحة مدير لإدارة المستخدمين والخطط ومؤشرات الإيرادات.
- CSRF protection + prepared statements + password_hash/password_verify.
- دعم RTL للعربية والكردية وLTR للإنكليزية.

## التشغيل المحلي
1. انسخ مجلد `linktree-iraq` إلى مجلد الويب المحلي مثل `htdocs` في XAMPP.
2. أنشئ قاعدة البيانات باستيراد ملف `database.sql` في phpMyAdmin أو MySQL CLI.
3. عدّل بيانات الاتصال بقاعدة البيانات في `config.php` إذا لزم الأمر.
4. افتح `http://localhost/linktree-iraq/`.
5. أنشئ حساباً جديداً من صفحة التسجيل.
6. لجعل الحساب مديراً نفّذ:

```sql
UPDATE users SET role='admin' WHERE username='YOUR_USERNAME';
```

ثم سجّل الخروج والدخول مجدداً لتظهر لوحة المدير.

## ملاحظات الإنتاج
قبل النشر الفعلي على VPS يجب نقل بيانات الاتصال إلى متغيرات بيئة، تفعيل HTTPS، إضافة rate limiting وOTP حقيقي لتأكيد الهاتف/البريد، وتوصيل بوابة دفع فعلية. جداول الدفع والاشتراكات موجودة كأساس لذلك.
